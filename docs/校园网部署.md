## 四、日常操作

### 开机后自动启动

开机登录后会自动弹出两个最小化窗口（主站 + 留言），无需操作。

### 手动启动

双击项目根目录的 **`启动服务器.bat`**。

### 停止

关掉那两个最小化窗口（窗口标题「长征-主站8088」「长征-留言8899」）。

### 检查是否在跑

```powershell
netstat -ano | findstr ":8088"
netstat -ano | findstr ":8899"
```

有输出就是在跑。

## 五、常见问题

### Q1：同学打不开怎么办

| 检查 | 命令/操作 |
|---|---|
| ① 服务在跑吗 | `netstat -ano \| findstr ":8088"` |
| ② IP 还是 38 吗 | `ipconfig`，看 WLAN 的 IPv4 地址 |
| ③ 同一个网段吗 | 对方 IP 也应是 `192.168.235.x` |
| ④ 防火墙 | 见 Q2 |

### Q2：防火墙拦了怎么办

**需要管理员权限**，在管理员 PowerShell 里跑：

```powershell
New-NetFirewallRule -DisplayName "长征网站-8088" -Direction Inbound -Protocol TCP -LocalPort 8088 -Action Allow
New-NetFirewallRule -DisplayName "长征网站-8899" -Direction Inbound -Protocol TCP -LocalPort 8899 -Action Allow
```

### Q3：IP 变了怎么办

这台机器现在是 DHCP 分配，重启路由可能变。

**根治**：在路由器里给本机 MAC 绑定固定 IP（DHCP 保留）。

**临时**：`ipconfig` 查新 IP，把新地址发出去。

### Q4：想让校外的人也能看

在服务器上装 cpolar：

```powershell
# 解压 cpolar.zip 后
cpolar authtoken <你的token>
cpolar http 8088 -log=stdout
```

拿到 `https://xxx.cpolar.r8.top` → 校内外都能访问，**不用备案**。
