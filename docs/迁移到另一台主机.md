# 网站迁移到另一台主机

> 适用于：把「长征 · 重走长征路」整套站点搬到另一台电脑/服务器。
> 迁移包：`长征网站-迁移包.zip`（181.8 MB，**已排除开发草稿和测试数据库**）

---

## 一、只需要 3 步

```
① 拷迁移包  →  ② 装 Node  →  ③ 双击启动
```

---

## 二、准备：目标主机需要什么

| 项 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10/11 或 Linux | 都支持 |
| 磁盘 | **至少 1 GB 空闲** | 解压 193 MB + Node 34 MB |
| 内存 | 2 GB 以上 | 实际只用约 110 MB |
| Node.js | **22 或更高** | 必装（见第三步）|

**不需要**：数据库（SQLite 随项目）、web 服务器（nginx）、任何 npm 包。

---

## 三、Windows 主机迁移步骤

### 第 1 步：拷贝并解压

把 `长征网站-迁移包.zip` 拷到目标主机，解压到任意目录，例如：

```
D:\changzheng\
```

解压后应该看到：

```
D:\changzheng\
├── index.html
├── css\  js\  fonts\  assets\
├── server\server.js
├── competition-timeline\
├── docs\
└── 启动服务器.bat
```

### 第 2 步：装 Node.js（**这是唯一要下载的东西**）

| 项 | 内容 |
|---|---|
| 下载地址 | `https://npmmirror.com/mirrors/node/v22.20.0/node-v22.20.0-win-x64.zip` |
| 大小 | 34 MB |
| 安装方式 | **解压即用**，解压到 `C:\changzheng-runtime\` |
| 验证 | 打开 PowerShell，执行 `C:\changzheng-runtime\node.exe -v`，应显示 `v22.20.0` |

> 也可以装官方安装包（nodejs.org 的 .msi），那样 `node` 会在 PATH 里，
> 但需要管理员权限；解压版不需要。

### 第 3 步：改启动脚本里的 Node 路径（如果解压位置不同）

打开 `启动服务器.bat`，确认这一行指向你的 Node：

```bat
set NODE=C:\changzheng-runtime\node.exe
```

如果你的 Node 装在别处，改成实际路径。

### 第 4 步：启动

双击 **`启动服务器.bat`**。

会弹出两个最小化窗口：

- 「长征-主站8088」
- 「长征-留言8899」

### 第 5 步：查新 IP 并访问

```powershell
ipconfig
```

找「无线局域网适配器 WLAN」或「以太网」的 IPv4 地址，例如 `192.168.235.38`。

访问：

```
http://新IP:8088/?demo=1
```

### 第 6 步：配开机自启（可选）

把 `启动服务器.bat` 的快捷方式放到：

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\
```

（按 `Win+R`，输入 `shell:startup` 可直接打开这个目录）

## 四、Linux 主机迁移步骤

### 第 1 步：上传并解压

```bash
scp 长征网站-迁移包.zip user@服务器IP:/opt/
cd /opt
unzip 长征网站-迁移包.zip -d changzheng
```

### 第 2 步：装 Node.js

```bash
# 方式一：官方源（Debian/Ubuntu）
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
node -v      # 应显示 v22.x

# 方式二：二进制解压（任何发行版）
wget https://npmmirror.com/mirrors/node/v22.20.0/node-v22.20.0-linux-x64.tar.xz
sudo tar -xf node-v22.20.0-linux-x64.tar.xz -C /opt
sudo ln -s /opt/node-v22.20.0-linux-x64/bin/node /usr/local/bin/node
```

### 第 3 步：启动测试

```bash
cd /opt/changzheng
node server/server.js &
node competition-timeline/server/server.js &

curl http://127.0.0.1:8088/          # 应返回 200
```

### 第 4 步：配 systemd 开机自启

创建 `/etc/systemd/system/changzheng.service`：

```ini
[Unit]
Description=Changzheng main site
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/changzheng
ExecStart=/usr/bin/node server/server.js
Restart=always
Environment=PORT=8088

[Install]
WantedBy=multi-user.target
```

再建一个留言服务的（改端口 8899 和路径）：

```ini
[Service]
WorkingDirectory=/opt/changzheng
ExecStart=/usr/bin/node competition-timeline/server/server.js
Restart=always
Environment=PORT=8899
```

启用：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now changzheng
sudo systemctl enable --now changzheng-comments
sudo systemctl status changzheng
```

### 第 5 步：开放防火墙

```bash
sudo ufw allow 8088/tcp
sudo ufw allow 8899/tcp
```

## 五、数据库怎么处理

迁移包**默认不含数据库**（`server/data.db` 已排除）。

| 你的需求 | 做法 |
|---|---|
| **全新开始**（不要旧用户数据）| 什么都不用做，首次启动自动建库 |
| **保留用户和进度** | 见下 |

### 保留旧数据的做法

**必须停服务**再复制（SQLite WAL 模式的坑）：

```powershell
# 1. 在旧主机上停掉服务
# 2. 复制三个文件（不是只有 data.db）
copy server\data.db        D:\changzheng\server\
copy server\data.db-wal    D:\changzheng\server\
copy server\data.db-shm    D:\changzheng\server\

copy competition-timeline\server\data.db*  D:\changzheng\competition-timeline\server\
```

**或者**在旧主机上先做 checkpoint，把 WAL 合并回主文件：

```bash
sqlite3 server/data.db "PRAGMA wal_checkpoint(TRUNCATE);"
```

然后只复制 `data.db` 即可。

| 检查项 | 命令/操作 | 期望 |
|---|---|---|
| 主站能开 | 浏览器 `http://新IP:8088/?demo=1` | 显示欢迎页 |

| 留言接口 | `http://新IP:8088/api/comments` | 返回 JSON |
| 后台 | `http://新IP:8899/admin` | 登录页 |

## 七、常见问题

### Q1：启动脚本双击闪退

| 原因 | 排查 |
|---|---|
| Node 路径不对 | 打开 bat，确认 `set NODE=` 指向真实路径 |
| 端口被占用 | `netstat -ano \| findstr ":8088"`，关掉占用的进程 |
| 中文路径问题 | 解压到**纯英文路径**（如 `D:\changzheng`）试 |

### Q2：别的电脑打不开

| 检查 | 命令 |
|---|---|
| 服务在跑 | `netstat -ano \| findstr ":8088"` |
| IP 对不对 | `ipconfig` |
| 同网段 | 对方 IP 应为同一网段 |
| 防火墙 | 管理员 PowerShell 加规则（见下）|

```powershell
New-NetFirewallRule -DisplayName "长征网站-8088" -Direction Inbound -Protocol TCP -LocalPort 8088 -Action Allow
New-NetFirewallRule -DisplayName "长征网站-8899" -Direction Inbound -Protocol TCP -LocalPort 8899 -Action Allow
```

### Q3：想在新主机上也做内网穿透

```powershell
# 拷 cpolar.exe，然后
cpolar authtoken <你的token>
cpolar http 8088 -log=stdout
```

拿到新的 `https://xxx.cpolar.r3.cpolar.cn`。

### Q4：迁移后 3D 地图不显示

检查 `assets/map3d/heightmap.png`（542 KB）和 `js/vendor/three.min.js`（594 KB）是否在包内。

```powershell
Get-ChildItem assets\map3d, js\vendor
```
