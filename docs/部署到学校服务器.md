# 部署到学校内网服务器

> 先判断学校给你的是哪种空间，再选对应方案。

---

## 一、先问清楚：学校给的是哪种？

| 类型 | 特征 | 走哪个方案 |
|---|---|---|
| **A. 网站目录**（静态空间）| 只能说“传文件到某个目录”，用 Apache/Nginx 直接托管 | **方案 A（纯静态）** |
| **B. 服务器/虚拟机** | 给一台机器（Linux/Windows），能装软件、开端口 | **方案 B（整站）** |

**大多数学校给的其实是 A（网站目录）**，因为静态空间最省管理成本。

---

## 二、方案 A：纯静态部署（不需要 Node）

### 适合什么

- 学校只给一个网站目录（如 `\\server\web\cz\` 或 `/var/www/html/cz/`）
- 你只能上传文件，不能装程序

### 功能会降级（重要）

| 功能 | 静态版 |
|---|---|
| 路线图 / 11 个节点 | ✅ 完整 |
| **11 张学生绘画** | ✅ 完整 |
| 3D 沙盘 | ✅ 完整 |
| 节点视频 | ✅ 完整 |
| 答题（前端判分）| ✅ 可以 |
| 打卡进度 | ⚠️ **只存当前浏览器**（换设备/清缓存就丢）|
| **账号注册 / 登录** | ❌ **没有** |
| **跨设备进度同步** | ❌ 没有 |
| **专题站留言** | ❌ 没有（静态页面能看，不能留言）|
| **排行榜 / 积分赛** | ❌ 没有 |

**结论**：静态版适合“看一眼、学一遍”的展示场景，**不适合需要记录成绩的教学场景**。

### 部署步骤

#### 第 1 步：拿到静态包

```
C:\Users\韩贝台木公\Desktop\长征网站-纯静态版.zip   （146.9 MB）
```

包内结构：

```
index.html
favicon.svg
css/  js/  fonts/  assets/
competition-timeline/     ← 专题站静态页
```

#### 第 2 步：上传到学校目录

| 方式 | 命令/操作 |
|---|---|
| **Windows 共享盘** | 直接拖文件 |
| **FTP / SFTP** | FileZilla / WinSCP 上传 |
| **SSH**（Linux）| `scp -r 长征网站-纯静态版/* user@server:/var/www/html/cz/` |

**建议路径**：`/cz/` 或 `/changzheng/`（一个子目录，不占根目录）

#### 第 3 步：访问时必须加 `?mock=1`

**这一步最关键**，不加会白屏（因为会去请求不存在的 `/api/*`）。

正确访问地址：

```
http://学校服务器IP/cz/?mock=1
http://学校域名/cz/?mock=1
```

**为什么**：项目默认按协议判断模式 —— 静态空间是 `http://`，会被判定为“有后端”，于是去请求 `/api/*`（不存在）→ 失败。加 `?mock=1` 强制走浏览器内数据。

#### 第 4 步：生成二维码

把最终地址（带 `?mock=1`）生成二维码，贴到展板或发给学生。

## 三、方案 B：整站部署（需要 Node）

### 适合什么

- 学校给一台服务器/虚拟机
- 能装 Node、能开端口（8088、8899）

### 功能完整

| 功能 | 状态 |
|---|---|
| 账号注册 / 登录 | ✅ |
| 云端进度（换设备不丢）| ✅ |
| 专题站留言 | ✅ |
| 排行榜 / 积分赛 | ✅ |
| 后台管理 | ✅ |

### 部署步骤

#### 第 1 步：拿完整迁移包

```
C:\Users\韩贝台木公\Desktop\长征网站-迁移包.zip   （181.8 MB）
```

#### 第 2 步：上传解压

```bash
scp 长征网站-迁移包.zip user@server:/opt/
cd /opt && unzip 长征网站-迁移包.zip -d changzheng
```

#### 第 3 步：装 Node.js 22

```bash
# Ubuntu / Debian
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs

# 或二进制（任何发行版，不需要 root）
wget https://npmmirror.com/mirrors/node/v22.20.0/node-v22.20.0-linux-x64.tar.xz
tar -xf node-v22.20.0-linux-x64.tar.xz -C /opt
ln -s /opt/node-v22.20.0-linux-x64/bin/node /usr/local/bin/node
```

#### 第 4 步：启动两个服务

```bash
cd /opt/changzheng
node server/server.js &
node competition-timeline/server/server.js &

curl http://127.0.0.1:8088/    # 应返回 200
```

#### 第 5 步：配 systemd（开机自启）

`/etc/systemd/system/changzheng.service`：

```ini
[Unit]
Description=Changzheng main site
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/changzheng
ExecStart=/usr/bin/node server/server.js
Restart=always
Environment=PORT=8088

[Install]
WantedBy=multi-user.target
```

留言服务同理（端口 8899，路径 `competition-timeline/server/server.js`）。

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now changzheng
sudo systemctl enable --now changzheng-comments
```

#### 第 6 步：开放防火墙

```bash
sudo ufw allow 8088/tcp
# 8899 不要对外开放（只给主站反代）
```

#### 第 7 步：访问

```
http://学校服务器IP:8088/?demo=1
```

## 四、向信息中心申请时，这样说

### 要静态空间（方案 A）

> 我需要在学校网站下放一个**纯静态的党史教育网页**，用于学生活动展示。
> 只需要一个子目录（约 150 MB，主要是视频和图片），
> 不需要数据库、不需要后台程序，Apache/Nginx 静态托管即可。

### 要服务器（方案 B）

> 我需要一台内网服务器部署一个**带账号和留言功能的教育网站**。
> 要求：
> - Linux（Ubuntu/CentOS 均可），2 核 2 GB 足够
> - 能装 Node.js 22（或给我解压权限）
> - 开放 **8088 端口**给校园网访问
> - 8899 端口只给本机（不需要对外）
> - 给我一个固定内网 IP

**如果信息中心问“要不要备案”**：

> 这是**校内使用**，不对外网开放，用的是内网 IP，不涉及域名备案。

## 五、两种方案对比

| 维度 | 方案 A（纯静态）| 方案 B（整站）|
|---|---|---|
| 需要装软件 | ❌ 不需要 | ✅ Node.js 22 |
| 需要开端口 | ❌ 不需要（走 80）| ✅ 8088 |
| 申请难度 | ⭐ 简单 | ⭐⭐ 中等 |
| 功能完整度 | **约 60%**（无账号/留言/排行）| **100%** |
| 数据持久化 | ❌ 只在浏览器 | ✅ SQLite 云端 |
| 适合场景 | 展示、参观、看一遍 | 教学活动、要记成绩 |

## 六、常见问题

### Q1：静态版打开是白屏

**原因**：地址没带 `?mock=1`。

**正确**：`http://serverIP/cz/?mock=1`（注意别漏掉问号和等号）

### Q2：静态版能答题，但成绩存不住

**这是设计**：静态版没有后端，进度存 `localStorage`。

**想存住** → 走方案 B。

### Q3：学校只给 80 端口，怎么办

**方案 A 天然用 80**，没有这个问题。

**方案 B** 如果只能用 80，需要 nginx 反代：

```nginx
server {
    listen 80;
    server_name cz.school.edu.cn;
    location / {
        proxy_pass http://127.0.0.1:8088;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### Q4：上传太慢（150 MB）

| 优化 | 说明 |
|---|---|
| U 盘拷贝 | 同机房最快 |
| 分离视频 | 视频放别的目录，或先传不带视频的版本 |
| 只传关键页 | 如果只展示某几个节点 |

**不带视频的版本**：删除 `assets/video/` 后约 **57 MB**。
